# Рабочие шаблоны

Используй только нужные для запрошенного этапа. Пустую таблицу не выдавай за
проведённую работу: проставь «нет данных» и объясни ограничение.

## Бриф

```markdown
# Бриф: [тема]
Статус: гипотеза / проверена выдача / выбранная тема.
Аудитория и её ситуация:
Основной вопрос и результат чтения:
Бизнес и полезный следующий шаг:
Язык, регион, поисковик:
Существующая страница по теме: URL / не найдено / сайт не проверен.
Главный запрос и дополнительные: измеренные / гипотезы.
Почему подходит формат статьи:
Что раскрываем и чего не обещаем:
Фактура автора: предоставлена / что спросить.
Внешние источники и дата проверки:
Принятые решения и незакрытые вопросы:
```

## Доказательства

| Фраза | Значение | Регион | Период / операторы | Источник / файл | Получено |
|---|---|---|---|---|---|
| [точная фраза] | [число либо нет данных] | […] | […] | […] | […] |

Не добавляй колонку «суммарный спрос» для перекрывающихся запросов.

| Запрос | Поисковик, регион, дата | URL | Формат | Что открыто и проверено | Вывод |

| […] | […] | […] | статья / каталог / форум / другое | полный текст / сниппет / недоступно | […] |

| Утверждение | Статус | Доказательство | Где используется |
|---|---|---|---|
| […] | подтверждено / мнение автора / учебный пример / требует проверки | источник + дата либо ответ автора | раздел |

## Проверка

```markdown
# Проверка материала
Запрошенный этап:
Что реально проверено:
Проверял: автор работы / независимый проверяющий [если участвовал].
Место → проблема → исправление → результат повторной проверки:
Что осталось непроверенным и как влияет на использование:
Итог: бриф / черновик / пакет к публикации.
```

## Передача на сайт

```markdown
# Пакет к публикации
Текст: [локальный путь]
Title:
Description:
Предлагаемый URL: [не выдавать за существующий]
Иллюстрации: [существующие файлы + alt; отдельно — задания на недостающие]
Ссылки: [что проверено; что ещё требуется]
Применение: локально / запись разрешена [точный объём] / опубликовано [проверенный URL].
Следующий шаг:
```

## План наблюдения

без оговорки. Сверяй определения метрик соответствующего сервиса.
