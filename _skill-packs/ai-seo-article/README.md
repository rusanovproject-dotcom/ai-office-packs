# SEO-статья с ИИ

Сохраните папку целиком, включая `references/`, в `.agents/skills/ai-seo-article/` для Codex или в `.claude/skills/ai-seo-article/` для Claude Code. В новой сессии укажите тему, сайт, аудиторию, язык, регион и доступные материалы. Начните с одной пробной статьи и сохраните черновик на проверку.
